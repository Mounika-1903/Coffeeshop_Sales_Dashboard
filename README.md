# Coffeeshop_Sales_Dashboard

📊 Overview

An interactive Coffee Shop Sales Dashboard created using Microsoft Excel to analyze coffee shop sales performance, customer footfall, product categories, store-wise performance, and purchasing trends.

The dashboard provides an interactive view of key business metrics and helps identify important sales and customer trends.

🎯 Objective

To analyze coffee shop sales data and transform raw data into meaningful business insights using an interactive Excel dashboard.

🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- KPI Cards
- Data Cleaning
- Data Visualization
- Dashboard Design
- Interactive Filtering

📌 Dashboard Features

- Total Sales
- Total Orders
- Customer Footfall
- Product Category Analysis
- Store-wise Sales Analysis
- Store-wise Footfall Analysis
- Peak Hour Analysis
- Order Size Analysis
- Sales Performance Analysis
- Interactive Filters

📈 Key Insights

- Peak orders were recorded during morning hours.
- Coffee products generated the highest sales contribution.
- 24 Hell's Kitchen store performed strongly in sales and customer footfall.
- Large-size orders contributed significantly to total orders.
- The dashboard provides an interactive view of coffee shop sales and customer purchasing trends.
